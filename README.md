## About

ShoppingList App is an Android application designed to make everyday shopping list management simple and convenient.

The application provides a clean and intuitive interface for adding and managing shopping items, with Firebase integration for cloud-based functionality.

Built using modern Android development technologies, this project demonstrates practical experience with Kotlin, Jetpack Compose, Material 3, Firebase, and Android Studio.

---

## Features

- Add shopping items
- Enter item details
- View shopping list
- Manage shopping items
- Remove shopping items
- Firebase integration
- Modern Jetpack Compose UI
- Responsive Android interface
- Lightweight and user-friendly experience
